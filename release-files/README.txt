TUIN'S TOP DOOM - QUICK START
=============================

1. Extract the entire ZIP to a normal folder.
2. Double-click DoomTopModeLauncher.exe.
3. Confirm the detected IWAD, choose whether to load the slower Voxel Doom pack,
   and press LAUNCH.
4. The launcher searches common Steam/GOG locations for DOOM2.WAD or DOOM.WAD.
5. If it cannot find one, select your legally owned IWAD with Browse.

The game remembers the selected IWAD for next time. Delete
DoomTopModeLauncher.ini or run DoomTopModeLauncher.exe --choose-iwad to choose
another one.

Optional voxel models
---------------------
Voxel Doom is not redistributed with this project. Put VoxelDoom_v2.4.pk3 in
this folder or in an "addons" subfolder and it will load automatically. The
launcher also checks your Downloads folder. Run with --no-voxels to disable it.

Controls
--------
WASD       Move
Mouse      Aim
Use        Inspect/equip a nearby rolled weapon
Q / E      Rotate camera
V          Cycle camera pitch
[ / ]      Zoom
C          Toggle aim assist
F          Toggle flashlight
B          Toggle automatic camera avoidance
N          Toggle wall cutout
Z          Recenter camera

Important
---------
No commercial Doom IWAD is included. You must own Doom or Doom II.
UZDoom is GPLv3+; its license files are included inside the engine folder.
Voxel Doom remains a separate optional download under its own license.
